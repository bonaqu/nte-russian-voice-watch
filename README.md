# NTE Russian Voice Watch

Публичный независимый мониторинг официальной русской озвучки **NTE: Neverness to Everness**.

Сайт считает время с глобального релиза, проверяет официальные региональные страницы и языковые поля магазинов, сохраняет историю запусков и показывает доказательства. Русский интерфейс и субтитры никогда не выдаются за русский дубляж.

> Проект не связан с Hotta Studio, Perfect World Games, Valve или Sony Interactive Entertainment.

## Что уже готово

- адаптивный тёмный интерфейс без UI-фреймворков;
- счётчик до секунд с остановкой при подтверждённом выходе озвучки;
- график времени после релиза и контрольные отметки;
- пасхальные сообщения на 30, 50, 100, 150, 250, 365, 500, 750, 1000, 1250, 1500 и 2000 дней;
- автоматические проверки четыре раза в сутки;
- английские, русские, китайские, японские и корейские правила обнаружения;
- отдельный анализ Steam `Full Audio` и PlayStation `Voice` / `Screen Languages`;
- история всех запусков с отпечатками доказательств;
- отдельная русско-английская презентация для разработчиков;
- кнопки копирования и системного шаринга;
- Open Graph-карточка для Telegram и социальных сетей;
- PWA с установкой на телефон и офлайн-кэшем;
- автоматические тесты, GitHub Issue при новом сигнале и необязательное Telegram-уведомление;
- отсутствие платных API, аналитики, cookie-баннеров и серверной базы данных.

## Почему выбран GitHub Pages

GitHub Pages подходит лучше Cloudflare Workers для этого проекта:

1. сам сайт полностью статический;
2. GitHub Actions бесплатно выполняет Python-проверку по расписанию;
3. история хранится рядом с кодом и видна публично;
4. не нужен отдельный сервер, D1, KV или платный API;
5. публикация и мониторинг воспроизводимы из одного репозитория.

## Быстрый запуск через браузер

Подробная инструкция со скриноподобными шагами находится в [`DEPLOYMENT.md`](DEPLOYMENT.md). Минимальный путь:

1. Создать **публичный** репозиторий `nte-russian-voice-watch` в аккаунте `bonaqu`.
2. Распаковать архив и загрузить **содержимое папки**, а не саму внешнюю папку, в корень репозитория.
3. Открыть `Settings → Pages` и выбрать `Source: GitHub Actions`.
4. Открыть `Actions → Monitor NTE Russian Voice → Run workflow`.
5. После успешного запуска открыть:

   `https://bonaqu.github.io/nte-russian-voice-watch/`

Все абсолютные ссылки и Open Graph-метаданные уже настроены под этот адрес.

## Локальный запуск на Windows

Нужен установленный Python.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\serve.ps1
```

Затем открыть `http://localhost:8080`.

Нельзя нормально проверять PWA двойным кликом по `index.html`: Service Worker и загрузка JSON требуют HTTP-сервера.

## Локальная проверка автоматики

```powershell
python -m pip install -r requirements.txt
python -m pytest -q
python scripts\check_sources.py
python scripts\build_site.py
```

После проверки изменятся JSON-файлы в `data/`, а готовая версия для публикации появится в `dist/`.

## Как принимается решение

Публичные состояния:

| Состояние | Значение |
|---|---|
| `NO_RUSSIAN_VOICE` | минимум два независимых типа источников подтверждают отсутствие русского полного звука |
| `POSSIBLE_MENTION` | найдено релевантное, но неоднозначное упоминание |
| `CONFIRMED_ANNOUNCEMENT` | официальный источник прямо анонсировал русскую озвучку |
| `RUSSIAN_VOICE_RELEASED` | структурированное поле магазина или официальный релизный текст подтверждает доступность |
| `UNKNOWN` | успешных данных недостаточно; монитор не угадывает |

Подробная логика находится в `scripts/detector.py`, а регрессионные проверки — в `tests/test_detector.py`.

## Какие источники проверяются

Конфигурация находится в `data/sources.json`. По умолчанию включены:

- официальные региональные сайты NTE: EN, RU, CN, JP, KR;
- новые и недавно изменённые официальные статьи;
- Steam;
- PlayStation Store: США, Япония и Корея;
- официальный языковой анонс теста;
- официальный FAQ релиза.

Монитор не использует фанатские вики, ролики, Telegram-пересказы и публикации без первоисточника для автоматического подтверждения.

## Необязательные уведомления в Telegram

Бесплатный Telegram Bot API уже поддержан, но по умолчанию выключен.

В репозитории открыть `Settings → Secrets and variables → Actions → New repository secret` и создать:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather;
- `TELEGRAM_CHAT_ID` — ID личного чата или канала.

Уведомление отправляется только при переходе в `POSSIBLE_MENTION`, `CONFIRMED_ANNOUNCEMENT` или `RUSSIAN_VOICE_RELEASED`. Обычные проверки не спамят.

## Обновление адреса при другом имени репозитория

Проект заранее настроен для:

- пользователь: `bonaqu`;
- репозиторий: `nte-russian-voice-watch`.

При переименовании нужно выполнить глобальную замену:

```text
https://bonaqu.github.io/nte-russian-voice-watch/
https://github.com/bonaqu/nte-russian-voice-watch
```

Проверить файлы `index.html`, `appeal.html`, `robots.txt`, `sitemap.xml`, `data/status.json`, `scripts/check_sources.py` и `README.md`.

## Проверка готовности

Результаты локальных тестов и честные границы проверки описаны в [`VALIDATION.md`](VALIDATION.md). После публикации обязательно выполните первый ручной запуск monitor workflow.

## Честные ограничения

Нельзя гарантировать вечную работу любого веб-парсера: официальный сайт или магазин может изменить HTML, защиту от ботов или адрес страницы. Поэтому проект:

- показывает ошибки источников отдельно;
- не меняет статус на основании сетевого сбоя;
- хранит последнюю успешную проверку;
- имеет тесты и форму issue для сломанного парсера;
- использует несколько независимых источников.

Это готовый к развёртыванию проект, но не обещание, что сторонние сайты никогда не изменятся.
